## Failures found

The initial summary added query deltas but excluded source/bridge acquisition. Filtering counted survivors instead of candidates tested. `recompute` cached across queries rather than rebuilding as promised. `tree` never built a tree; its abstention was imposed. Disabled use never resumed. Snapshot restoration changed integer dictionary keys to strings and the resume path omitted future bridge arrivals. The learning constructor copied generator tables rather than parsing raw records. Targets were passed into query() for scoring (not used for inference, but unnecessary access). Proper scores and promised verification were absent. “No common interface” was too strong: bridge-pair semantics and a bijective common identity were supplied. Phase 3 repeats phase-0 questions, so not all queries are novel. An oracle with extra information is not an information-matched strong control.

## Repaired and strengthened comparison

Keep exactly the original 24 six-object worlds and queries. Convert the existing local transitions and category labels into 24 source records; learn tables by parsing these. Only an observation packet (source records, currently seen bridge prefix) goes to learners. Targets/latent IDs stay in the evaluator. The bridge records explicitly teach identity pairs; this design **does not discover what a bridge means**. The two transition types are unrelated under the unrestricted-bijection learner family; they are used for composition, not to constrain correspondence.

Methods: `separate` disables cross computation but retains all records; `persistent` initializes 720 uniform bijections, filters only new bridges, predicts by counting candidate outputs; `recompute` reconstructs local tables and all 720 maps from all current records before EACH query with no cache; `completion` uses the exact analytic posterior over unrestricted bijections (known pairs fixed, unused symbols uniformly matched), without enumerating maps; `point` chooses the first currently surviving map and treats it as certain (not necessarily wrong); `disabled` maintains the persistent state but disables composition for phases 0–2, enabling it in phase 3; `oracle` receives the full true map as an explicitly counted six-entry information gift. `point` also sees the same evidence and is an overconfidence control, not an externally gifted wrong map.

Preserve the uniform-bijection model to audit the original experiment. This posterior is exact **within that stipulated model**. It is not necessarily the Bayes posterior for the planted generator: the particular local categories/cycles can convey further constraints if their shared generative law is supplied. Record this limitation; do not assert zero cross-domain information in these source tables under every model. A no-bridge theorem uses a DIFFERENT explicit family allowing arbitrary maps with fixed local tables. Separate its mathematical counterexample from this empirical distribution.

`completion` is the crucial stronger control: exact inference from the same source/bridge history, matching probabilities with no 720-map search. Its code/analytic uniform-bijection rule is supplied, as is the enumerator's rule. No learned structural alignment should be claimed if this direct control matches all predictions. Unseen composed queries may still use an already taught pair; label query repetition and whether the specific correspondence queried was taught. The final inferred sixth pair follows from the supplied bijection assumption.
