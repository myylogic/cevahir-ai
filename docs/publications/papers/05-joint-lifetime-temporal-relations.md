# Representation, memory and temporal relations in one lifetime stream

**Muhammed Yasin Yılmaz**

CEV-2026-05 · Version 2026.11.24 · Published 2026-11-24

Research report / preprint. Not peer reviewed.

## Abstract

A joint stream combines representation expansion, regional memory and target change across 24 lives. A fixed expanded baseline matches final accuracy; fewer solves do not establish total efficiency. Label corruption and stale statistics remain negative controls. Temporal prediction with supplied lag features succeeds on informative input but fails after an uninformative training stream shifts.

## Interpretation of the findings

Components that work separately do not guarantee reliable learning under all the conditions of one life; the informativeness of the data stream is decisive.

Good prediction with supplied lags is not a general discovery of temporal relations or causal structure. The condition from which a later burst of corrupted data was removed is reported separately.
