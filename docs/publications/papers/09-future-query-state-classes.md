# The state required by future learning operations: an exact finite audit

**Muhammed Yasin Yılmaz**

CEV-2026-09 · Version 2026.11.24 · Published 2026-11-24

Research report / preprint. Not peer reviewed.

## Abstract

We compare state classes for all Boolean loss queries, observation counts and identity-only label edits on the same finite histories. Length plus signed label differences suffices for all future Boolean loss queries; identity edits impose a separate linear information bound. Exact enumeration checks 61,575 histories, 712,632 label writes and 358,020 appends with no count-formula or replay mismatches.

## Interpretation of the findings

Unknown future hypotheses do not always require the full histogram. The information required depends on which queries and operations are to be supported, before whether the hypotheses are known.

A fixed finite domain, all Boolean risks and exact correctness are used. A class count is not an efficient encoder or real-world learning performance; the general living-learning question remains open.
