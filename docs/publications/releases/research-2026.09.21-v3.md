# Cevahir 2026.09.21.3 — Checkpoint, Generation, Memory and Tools

**Author: Muhammed Yasin Yılmaz**

This edition expands technical book chapters 7–9, tying checkpoint identity and resume, token generation, retrieval and tool orchestration to actual Cevahir files, methods and executed examples. It also fixes the calculator argument-inference bug found during review: `2+3*4` now remains the complete expression and returns `14`, rather than silently computing `2+3`. Ambiguous or unsupported expressions no longer invent an addition operation.

- Twelve chapters; 115 second-level topics and 64 third-level subtopics; approximately 29,500 whitespace-delimited words including markup.
- Fifteen additional solved exercises and eighteen bibliography entries in the three expanded chapters.
- Five checkpoint and five generation/memory/tool example groups. Fixed logits and assigned vectors are explicitly identified as teaching fixtures.
- Seventy selected generation, agent, checkpoint and runtime tests passed, including 22 new calculator regression cases.
- Original calculator failure evidence, all nine research report source records and earlier negative research findings are preserved.
