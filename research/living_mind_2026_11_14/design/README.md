# Zihin — design working documents (not results)

Working documents of the "living mind" initiative started on 2026-11-14: a non-Transformer core that learns while
it lives. Everything here is a DRAFT kept in the repository so that it cannot be lost; nothing here is a result,
a frozen protocol or a novelty claim. Documents are replaced as the work proceeds.
