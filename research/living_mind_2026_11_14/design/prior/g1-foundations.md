## 2. `docs/research/EXPERIENCE_CONDITIONED_COMPUTE.md` = paper 01 (CEV-2026-01)

1. **Question.** Can externally verified feedback collected while running change which computation strategy is chosen later (H1), and can a cognitive-context prior usefully bias Mixture-of-Experts routing (H2), all under one shared request budget?
2. **Mechanism / state actually used.** A symbolic, bounded evidence ledger plus statistics derived from it on demand. No weight is trained.
   - *Stored*: `ExperienceRecord` = id, scope (user/session), identity = (model_revision, tokenizer_revision), hashed task bucket, hashed sample id, planned and executed strategy, status in {observed, budget_limited, error, cache}, cost, source ids, request id, timestamp, feedback events (`cognitive_management/research/experience.py:101-115`). No prompt or answer text. Capacity 256 records per scope, 128 scopes, 32 feedback events per record (`:138-140`).
   - *Update rules*: `observe()` appends, evicting the oldest record of a full scope (`:190-224`). `feedback()` accepts only sources {user, evaluator, tool_verified}; a newer event of the same source supersedes the older (`:226-253`). Quality of a record = minimum over sources of each source's latest value (`:255-260`).
   - *Derived preference* (`recommend`, `:262-338`), recomputed from records at every call ("Derive from records every time: correction, forget, and eviction cannot leave a stale learned preference in a separate cache", `:282-283`). For each (action, sample) only the latest record counts once. Weight `w = 2^(−age / half_life)` with half-life 604800 s (`:302`); cost transform `c' = cost/(1+cost)` (`:303`); `utility = Σw·q/Σw − 0.1·Σw·c'/Σw` (`:308-310`); `penalty = min(2, 0.5/sqrt(Σw))` (`:311`); `lower = utility − penalty`, `upper = utility + penalty`. The baseline is replaced only if baseline and candidate both have support ≥ 3 independent samples, the candidate has no retained negative evidence, and `candidate.lower > baseline.upper` (`:325-331`).
   - *Retraction*: `forget()` deletes the record, hence its effect on every later recommendation (`:340-355`).
   - *Controller*: task bucket = hash of (profile, decoding, system prompt, {query_type, domain, complexity_bin, uncertainty_bin, uncertainty_source, memory_present}) (`controller.py:91-105`). Modes `off / budget / shadow / adaptive` (`:107-110`). Optional exploration with recorded selection probability (`:113-119`), default rate 0 (`config.py:18`). Strategies are the four existing ones: direct, think1, debate2, tot (`controller.py:42-46`). Cost = mean of four normalised budget usages (`:140-143`).
   - *MoE prior*: `router_logits[B,T,E] + routing_bias[B,1,E]`, bias finite and in [−1, 1] (`mixture_of_experts.py:64-78, 191-194`), followed by the unchanged top-k and softmax (`:204-210`). The bias is a researcher-written per-domain profile; nothing is learned.
3. **Experimental design.** Contract tests only: "96 yeni hedefli test vakası ve mevcut akıştan seçilen 3 asenkron/cache regresyonu geçti" (`benchmarks/results/research_contract_verification_summary.json`; neural fixture 2 layers / width 8 / vocabulary 16). An offline replay harness over a fully observed synthetic table (`benchmarks/research/experience_replay.py`; fixture `benchmarks/research/fixtures/synthetic_routes.jsonl`: 4 train rows, 2 eval rows, 6 source groups) with four policies: frozen, adaptive, shuffled training feedback, negative feedback omitted (`experience_replay.py:38`). No model, no training, no real task.
4. **Results and labels.** The study's own status table (lines 90-96): budget, experience store, MoE prior = "IMPLEMENTED, STATICALLY VERIFIED, CHEAP-TEST VERIFIED"; offline table = "EXPERIMENT READY, CHEAP-TEST VERIFIED"; "Gerçek kalite/maliyet kazancı ve aktarım: EMPIRICAL VALIDATION PENDING". H1 and H2 are therefore **inconclusive** (never measured). No stored replay output exists in the repository (`.evolution/` is absent). *My check* (the 6-row fixture, output in the scratchpad `_checks/synthetic-replay.json`, not a repository artefact): frozen mean quality 0.35 / cost 0.10; adaptive 0.75 / 0.30 (switches to `think1` on the known bucket, stays on the baseline for the unseen bucket with reason `insufficient_baseline_support`); shuffled feedback 0.35 / 0.10 (`no_supported_advantage`); negative feedback omitted 0.35 / 0.10 (the baseline then has no support, so no switch). This shows mechanism behaviour on six hand-written rows and nothing else.
5. **Law / invariant claimed.** No theorem. Contracts [CONTRACT]: (a) an observation is not evidence of quality, only authenticated external feedback is; the critic's score is not external evidence; (b) repeating one sample adds no support; (c) a derived belief is a pure function of the retained evidence, so correction, forgetting and eviction retract it exactly; (d) the outcome of an action that did not run is never inferred ("This store never trains weights and never labels a route that did not execute", `experience.py:4-5`); (e) three state speeds with separate ownership: fast (request budget, stage, fixed prior), intermediate (verified experience and derived preference), slow (network weights).
6. **Limits.** Admitted: buckets are coarse heuristics; a preference is not a causal estimate; the penalty "kalibre edilmiş güven aralığı değildir"; shadow mode cannot produce evidence for untried alternatives; token accounting is reservation, not FLOPs; deleting a record does not unlearn weights. The paper edition's own two sentences: finding — "Deneyim gelecekteki hesaplama seçimini kalıcı bir kayıt üzerinden etkileyebilir. Bu etkiyi genel öğrenme veya gerçek görev başarımı artışı olarak sunmak için kanıt yoktur."; limit — "Yönlendirme grupları sezgiseldir; denenmemiş eylemlerin sonuçları seçilmiş eylem loglarından çıkarılamaz. Sabit MoE prior'ı öğrenilmiş uzman anlamı değildir." *Limits I see*: with exploration rate 0, a strategy that the pre-existing policy never selects for a task bucket never gains support there and so can never be recommended — the evidence lock that the later closed-loop study formalises; staleness is a wall-clock half-life, not an inferred change; the mechanism selects among four pre-existing strategies and so changes which computation runs, not what the system can compute; H2 has no measurement of any kind.
7. **Implication.** *Mechanisms to reuse*: provenance-carrying evidence records; beliefs recomputed from retained evidence (exact retraction, cf. Law 13 below); one-count-per-independent-sample; per-source supersession; logged selection propensity; compute budget as a first-class resource shared by every internal call; evidence indexed by the identity of the machinery that produced it (in a self-modifying core every belief must name the version of the constructor that generated its evidence). *Warning*: this is experience-conditioned routing around a frozen network, the snapshot paradigm with a ledger attached; it is not the unification of learning and running. *Open*: how to obtain evidence about computations that were never run.

## 3. `docs/research/FRONTIER_DISCOVERY_2026_09_20.md`

1. **Question.** Starting from capability rather than from the existing architecture, which missing capability is worth a research line: H1 acquire an executable operation from examples, H2 retract only the conclusions that depended on a changed assumption, H3 design a discriminating measurement that preserves the ability to continue the task, H4 rebuild the object/feature representation from a counterexample?
2. **Mechanism / state.** None implemented ("Yeni üretim kodu, eğitim veya model çalıştırması yapılmadı"). Proposed structure (lines 92-99): raw observation/intervention trace; an executable representation (small typed expression mapping a history to distinctions; free text does not count); an insufficiency witness (two histories merged by the representation, the compared action sequence, the diverging outcomes); bounded change search; independent test; accept-or-uncertain result. Interface `observe → predict → witness → propose_change → evaluate`. Key statement (line 55): "`R(h1)=R(h2)` eşitliği daha sonra yanlışlanabilir bir taahhüttür."
3. **Design.** One analytical two-row counterexample (A and B consume one shared capacity unit; the old representation keeps only B's own used flag) and a drafted experiment that was never run in this form: worlds with independent resources, shared capacities, pairwise and triple interactions; 2–4 objects, transfer to 5–6 renamed objects; conditions = fixed initial representation, full-history method, generic predicate invention, same-language search without witnesses, witness-bounded search, oracle upper bound; proposed limits 4,096 candidates, 32 nodes per expression, 256 observations per sample; pre-set continuation criterion "en az %95 doğru öngörü … en az %20 daha az dış gözlem" against the strongest same-language rival (line 115).
4. **Results and labels.** H1 "Yeni araştırma hattı olarak elendi" (it is program synthesis / programming by examples). H2 "Elendi. Mühendislik değeri yüksek" (truth maintenance / incremental computation). H3 "Ana hat olarak elendi" (active automata learning, reset learning). H4 "Koşullu seçildi", then its narrow advantage claim was eliminated by the witness audit (section 4). Two-row check [EXACT, by hand]: "Eski girdiler aynı, gerekli çıktılar farklı … en iyi doğruluk %50'dir." Status line: "CAPABILITY HYPOTHESIS / PRIOR-ART CHECKED, NOT EXHAUSTIVE / ANALYTICAL COUNTEREXAMPLE CHECKED / ARCHITECTURE PROPOSED / IMPLEMENTATION NOT STARTED / EMPIRICAL VALIDATION PENDING".
5. **Law.** Representation-loss bound [PROOF by the two-row table]: a deterministic predictor that reads only `R(h)` cannot be correct on two histories with `R(h1)=R(h2)` and different required outcomes; with equal weight the best accuracy is 50%. Scope: any fixed representation and task. The document states the limit of the claim itself: it "yalnız seçilmiş bilgi kaybının telafi edilemeyeceğini gösterir. Transformer'ların ilişki öğrenemediğini … göstermez."
6. **Limits.** Admitted: no learner run, novelty not established, and five named objections (answer hidden in the candidate language; victory over the wrong rival; noise mistaken for a new object; predictive structure mistaken for the world's one ontology; enlarging the representation on every error). *Limit I see*: H2 and H3 were dropped for lack of novelty, not for lack of use; both are functional needs of a living core (dependency-tracked retraction; information-seeking action that does not destroy the future).
7. **Implication.** *Requirement*: every representation the core adopts must be carried with its commitment (which histories it merges) and with what would falsify it. *Reusable*: the three senses of "new" (new to Cevahir / makes a measurable capability difference / absent from the literature — "Birincisi üçüncüsünün kanıtı değildir") and the five objections as an acceptance checklist for concept formation. *Open*: where candidate distinctions come from.

## 4. `docs/research/REPRESENTATION_WITNESS_AUDIT.md` + `research/representation_discovery/witness_audit.py` = paper 02 (CEV-2026-02)

1. **Question.** With the same candidate language, candidate order, observations and exact deterministic consistency test, does restricting representation search by insufficiency witnesses learn from fewer observations than plain search?
2. **Mechanism / state.** Purely symbolic. A context is (history of (target, succeeded) events, next target). Base representation key = "has the target already been claimed successfully" (`witness_audit.py:119-120`). 24 further candidates add one predicate `term relation threshold` with term in {active_count, success_count, failure_count, attempt_count}, relation in {lt, eq}, threshold in {0,1,2} (`:123-149`, `language()` `:169-176`), 25 candidates in one fixed order. A model = (representation, key→outcome table); an unseen key gives abstention, never a default (`:184-186`). Generic search builds the table per candidate and stops at the first contradiction (`:259-269`). Gated search first extracts at most one real opposite-outcome training pair per base key (`find_witnesses`, `:215-231`), rejects candidates that do not separate it (`:250-258`), then runs the same full check. Selection = first compatible candidate in the given order (`:197-199`). Every step is charged to an explicit work meter, witness construction included.
3. **Design.** Three deterministic worlds (`fixtures`, `:277-303`; rule at `:296`): independent resources, total capacity 1, total capacity 2. Train with 3 objects, evaluate on 5 differently named objects, histories of at most 2 claims, each a reset episode. Prefix sizes 3, 6, 12, 24, 39 labelled contexts, 155 held-out contexts each: 15 comparisons. Predictions are frozen before labels are used. Limits: 10 s, 1,000,000 total steps, 100,000 per search, 16 MiB traced; an interrupted comparison is `inconclusive`.
4. **Results and labels.** `benchmarks/results/representation_witness_audit.json`: `status: "equivalent"`, `coverage_complete: true`, 0.17 s, 86,324 accounted steps, peak 162,972 traced bytes. All 15 comparisons: identical ordered compatible set, tables, selected candidate, predictions and abstentions [EXACT]. At 39 contexts: independent → `target_active`, 155/155, work 7,845 (generic) vs 7,986 (gated); capacity 1 → `target_active+(active_count lt 1)`, 155/155, 3,111 vs 3,073; capacity 2 → `target_active+(active_count lt 2)`, 155/155, 3,981 vs 2,798. Decision: the claim "yetersizlik tanığıyla mevcut adayları filtrelemek daha az gözlemle öğrenir" was "tamamlanan deterministik arama biçiminde elendi" → **REFUTED** in that form. The proposal to shuffle witnesses across tasks was also withdrawn as an unfair control. 15 targeted tests pass (my count of `def test` = 15). The paper edition's own two sentences: finding — "Tanıkla filtrelemenin bu koşullarda yeni öğrenme avantajı sağladığı hipotezi elendi; negatif sonuç korunmuştur."; limit — "Sonuç, farklı bilgi erişimi, açık uçlu ifade üretimi, yaklaşık tutarlılık veya kesilen hesap bütçeleri için aynı üstünlük/eşdeğerlik iddiasını kurmaz."
5. **Law.** Witness-filter equivalence [PROOF, lines 13-16]: let `C_D(R)` = representation R never maps one key to two outcomes on data D, and `W_D(R)` = R separates each witness pair taken from D. Then `C_D(R) ⇒ W_D(R)`, hence `{R : C_D(R)} = {R : W_D(R) and C_D(R)}`. Completed searches in the same order therefore select the same candidate, fit the same table and (by inference, not tested) would request the same next observation. Scope: same language, same order, exact consistency, completed search. The filter can only reorder computation: "Bu bir hesap düzenlemesidir; daha fazla bilgi edinildiği anlamına gelmez."
6. **Limits.** Admitted: no noise, no approximate consistency, no open-ended expression generation, no active query policy, counters and thresholds supplied by the researcher ("'yoktan kavram oluşturma' … değildir"). *Limits I see*: (i) the equivalence is about completed searches, and interrupted ones are only marked inconclusive, so the regime of a living system with a per-step budget is exactly the untested one; the work counters do differ, in both directions (+1.8%, −1.2%, −29.7% at 39 contexts); (ii) "first compatible in the supplied order" is an unexamined prior — at 39 contexts the compatible set has 25, 8 and 4 members and nothing weighs them; (iii) from the JSON, not discussed in the report: at 3 contexts in the capacity-1 world the selected model answers 125 of 155 held-out contexts and is right on 5 (accuracy 0.032, coverage 0.806), i.e. a representation that is consistent so far can be confidently wrong when under-determined.
7. **Implication.** *Warning*: a need signal (the witness) does not add information; a concept-formation mechanism must say which of three things it changes — "hangi bilgiye erişildiğini, hangi ifadelerin üretilebildiğini veya sınırlı toplam hesapta neyin gerçekleştirilebildiğini" (line 77) — or it is the same search under a new name ("Aynı önermeyi yeni isimle yeniden denemek araştırma ilerlemesi sayılmayacak"). *Reusable*: the witness as the trigger for "a concept is needed" (two histories the current key merges, with different outcomes); abstention on an unseen key; frozen predictions before scoring; explicit work accounting that charges the method for its own setup; `inconclusive` instead of a win under a resource cut. *Requirement*: keep the whole compatible set as graded belief instead of the first member.

### 5.1 `FOUNDATIONS.md` — definitions, sufficiency, impossibility

1. **Question.** What does it mean, in measurable terms, that a system learned while living, and which guarantees are possible at all?
2. **Mechanism / state.** A formal contract, no code. Life: `a_t ~ π_{s_t}(· given o_t; b_t)`, `z_t = (o_t, a_t, f_t)`, `s_{t+1} = U(s_t, z_t; c_t)` (lines 13-17); `s` may hold numbers, probabilities, programs, graphs, validity conditions and the update procedure itself; "`U` sabit durum döndürürse hiçbir öğrenme gerçekleşmez". Intervention `J` resets transient context, makes raw history unreachable and loads only the declared learned state.
3. **Design.** Analytical; references to the four experiments below.
4. **Results.** Definitions and propositions, each with scope:
   - Learning gain [definition]: `R_{Q,B}(s) = E_{(x,y)~Q}[ℓ(Exec_B(J(s),x),y)]`, `G_{Q,B}(E) = R_{Q,B}(s_0) − R_{Q,B}(s_E)` (lines 23-26). `G>0` = successful learning on held-out `Q` under answer budget `B`; `G<0` = harmful learning. Capability is relative to task and budget: `C_{ε,B}(s) = {Q : R_{Q,B}(s) ≤ ε}` (line 33).
   - Persistence is robustness to a stated life intervention, not eternal freezing; the proposed contract is "geçerlilik koşulları sürdükçe tutulması, koşullar çürütüldüğünde geri çekilebilir olması"; candidate, rule in use and retracted rule are three statuses (one labelled structure suffices).
   - Deleting a record does not delete what it caused: "Tam geri alma için yeterli istatistiklerin ters güncellemesi, bağımlılık izleme veya yeniden hesaplama gerekir."
   - Constructive sufficiency [PROOF, lines 46-70]: for prime `p` and stable `f_i(x) = a_i x + b_i mod p` with trusted identity-bound feedback, two distinct inputs give `a_i = (y_1−y_0)(x_1−x_0)^{-1}`, `b_i = y_0 − a_i x_0`; this determines the function on all inputs because the difference of two candidates is a polynomial of degree at most one with two roots. Composition is closed: `f_j(f_i(x)) = (a_j a_i)x + (a_j b_i + b_j)`. Conclusion: separating running from learning "mantıksal zorunluluk değildir".
   - Hypothesis update [standard]: `V_{t+1} = {h ∈ V_t : h(x_t)=y_t}`; noiseless Bayes `q_{t+1}(h) ∝ q_t(h)·1[h(x_t)=y_t]`; mistakes ≤ `floor(log2 |H|)` for binary outputs, realisable noiseless target, majority prediction. Positive priors leave the same support, so the number of labels for exact identification does not change.
   - Data-processing inequality [PROOF via chain rule, lines 87-99]: if `S' = F(S,R)` with `R ⟂ W given S`, then `I(W;S') ≤ I(W;S)`. Yet `R_{Q,B}(S') < R_{Q,B}(S)` is possible for fixed `B` (search, composition, compilation).
   - Impossibility set [PROOF, lines 101-111]: (a) unseen distinction — two worlds equal on all received observations and different at `x*` admit no assumption-free strict improvement in both; (b) conflicting old/new answer on the same visible input — with a balanced hidden context independent per query the minimum mean error is 1/2; (c) finite capacity — `M` bits have at most `2^M` states, `N > M` independent binary facts cannot all be recalled (pigeonhole); (d) representation loss — if `φ(x)=φ(x')` and the required outputs differ, no head `g(φ(x))` is right on both; this does not force a larger embedding, "aynı bit bütçesini daha uygun kodlamak da mümkün olabilir"; (e) computability — experience cannot add an uncomputable function; expressible is not the same as reachable in bounded time.
   - Acceptance rule for controlled change [PROOF from Hoeffding + union bound, lines 113-123; not implemented]: for a candidate `s'` chosen before seeing the validation samples, with probability ≥ `1−δ`, for all `K` task distributions `R_j(s') − R_j(s_ref) ≤ d̄_j + sqrt(2 log(K/δ)/n)`. Example `K=20, δ=.05`, margin `.05` → about 4,794 independent samples per distribution (my arithmetic: 4,793.2). Sequential use needs e.g. `δ_t = 6δ/(π² t²)`; small per-step degradations accumulate unless measured against fixed references.
   - Meta-learning [definition]: prior tasks improve the learning curve on new tasks; the hyper-state `η_t` can be part of `s_t`, a fixed interpreter runs update rules as data, so no infinite chain of learners is needed.
5. **Law.** The package above. The headline: "bir denklem ailesi ve yapıcı yeterli mekanizma bulunmuştur; tek doğru ve bütün dünyalarda garantili bir yaşam boyu öğrenme formülü bulunmamıştır."
6. **Limits.** Admitted: "Bu metin bir yeni teori veya evrensel çözüm iddiası değildir"; the coefficients are parameters in the broad sense, so the experiment "'parametre diye kodlanamayan öğrenme'yi kanıtlamaz; gradyanla objective optimizasyonunun zorunlu olmadığını gösterir"; the acceptance rule was never run. *Limit I see*: the definition measures what the state can do under matched queries; it does not say how to choose `Q`, `B` or the intervention distribution — those choices carry the whole burden.
7. **Implication.** *Requirements*: (i) every claim of the new core is a triple (held-out `Q`, budget `B`, intervention `J`) with reset and transplant controls; (ii) "imagination" is bounded by the data-processing inequality: it may change what is reachable within `B`, it cannot add world evidence; (iii) a "how real is this construction" measure must be an external-evidence statement with a sample-size bill of the Hoeffding kind, or a proof; (iv) the update procedure may live in the state (this is how "the way of constructing improves" is expressible without regress). *Warning*: the five impossibilities are the walls; a design that promises zero forgetting, zero wrong learning and unbounded new capacity in bounded state is promising against proofs.

### 5.3 `ADAPTATION_EXPERIMENT.md` + `adaptation_experiment.py` — learning to learn and negative transfer

1. **Question.** Can a small persistent state updated across earlier tasks make new tasks of the same family easier, and what happens when the family changes?
2. **Mechanism / state.** Bayesian version space with a learned family prior. Inputs `x ∈ {0,1}^6`; 128 affine Boolean hypotheses `f_{a,b}(x) = (a·x + b) mod 2` (`adaptation_experiment.py:26-29`), partitioned by the designer into three families by the Hamming weight of `a`: sparse (1–2), dense (4–5), rest; sizes 42, 42, 44 (`:30-36`). Within a task: `V_{k+1} = {h ∈ V_k : f_h(x_k) = y_k}` and prediction by prior mass on the survivors (`predict_one`, `:45-49`). Across tasks the whole persistent state is three numbers: `α_{g(h)} ← α_{g(h)} + 1` when a task has been identified by its labels (`:148`), `P_η(h) = (α_{g(h)}/Σα)/|H_{g(h)}|` (`probabilities`, `:39-42`), initial `α = (42,42,44)/128` (total pseudo-count 1, uniform over hypotheses, `:137`).
3. **Design.** 40 seeds; even seeds train on sparse, odd on dense. Per seed: 24 training tasks (mean 194.4 labels in total), then 8 unseen same-family and 8 unseen other-family tasks; per test task 16 queries and 48 never-labelled held-out inputs; hyper-state frozen at test, within-task learning continues. Methods: `uniform_reset`, `learned_family`, `scrambled_family` (same group sizes, hypotheses assigned at random). Intervals: mean ± 1.96 SE over seeds, no multiplicity correction. Stability counterexample: two complementary functions A then B.

### 5.4 `CLOSED_LOOP.md` + `closed_loop_experiment.py` — learning closes its own evidence

1. **Question.** Can learned avoidance stop further learning, and what reopens it: randomness, any deviation, internal state, or planning over future information?
2. **Mechanism / state.** A 240-step life with one shared failed attempt at `t=0`; waiting yields the same symbol in every world; only an attempt returns success or failure; reward +1 / `−c` / 0. Learner state: `learned_success` flag and `last_failure` time; the policy reads the internal age `t − last_failure` (`closed_loop_experiment.py:59-74`). ### 5.5 `UNKNOWN_CHANGE.md`, `UNKNOWN_CHANGE_AUDIT.md` + `unknown_change_experiment.py` — the expectation of change is itself learned

1. **Question.** If the rate at which a learned limit becomes false is unknown, can the system's own probe results change when it will retest, and what can never be guaranteed?
2. **Mechanism / state.** Finite Bayesian mixture over hazards `h ∈ {0, .002, .02}` with weights 1/3 (`unknown_change_experiment.py:18-20`); absorbing opening; noiseless probes. Survival `Z(s) = Σ_i w_i (1−h_i)^s` (`:24-25`). The complete failure history has the sufficient statistic `f` = last failure time: `P(h_i given failures) = w_i (1−h_i)^f / Z(f)` (`posterior`, `:28-30`). Two separately recorded changes: passing time changes the prediction `p(t,f) = 1 − Z(t)/Z(f)` but not the weights; only a real new failure sets `f ← t` and updates the weights. Decision: `V(t,f) = max{ V(t+1,f), p(t,f)(T−t+1) + (1−p(t,f))[−c + V(t+1,t)] }` (`mixture_plan`, `:33-44`).
3. **Design.** `T = 240`, costs 1 and 20; controls `frozen_hyperprior` (weights held at 1/3; coherent for a different model in which the rate is redrawn after each failure, `:47-62`), `fixed_hazard_001`, `never_probe`, and an oracle knowing the true hazard (upper reference only). Exact expectation over all opening dates and the tail for each true hazard, including the out-of-support stress hazard 0.08 chosen before the first run. No Monte Carlo.
4. **Results and labels** (`results/unknown_change.json`, [EXACT]):

   | Policy | Prior-average utility, c=1 | c=20 |
   |---|---:|---:|
   | updated mixture | 69.527959 | 37.323585 |
   | frozen hyper-prior | 65.668642 | 26.621452 |
   | fixed hazard .01 | 66.654044 | 26.361483 |
   | never probe | 0 | 0 |
   | oracle hazard | 73.593780 | 54.576609 |

   The Bellman value equals the independent enumeration to 1e-8. In the never-opening world at c=1 the learner probes at 16, 33, 52, 74, 99, 128, 161, 199 (frozen: 18 probes; fixed: 16) and its weight on "never changes" rises from .3333 to .59195 while the fast component falls to .01062; at c=20 it probes once, at step 83 (frozen: 49, 101, 160). **Supported**: "Yeniden sınama beklentisi yalnız dışarıdan ayarlanabilir — Zorunluluk iddiası reddedildi".
   Negative results: c=20, true `h=.02`: updated 124.71993 vs frozen 150.99167; out-of-support `h=.08`: 157.82428 vs 190.77203 (oracle 212.16658); `h=.002`, c=20: updated 7.25083 vs frozen −11.12732 while finding only 40.13% of openings. Label: "Doğru Bayes güncellemesi her alt dünyada daha iyi davranış verir — Elendi".
   Evidence-counting control (`controls`, `:125-148`): failures at 10, 35, 90, 150 give the same posterior as a single failure at 150: (.559005, .413997, .026998). Label: "Çok başarısızlık bağımsız çok kanıt demektir — Bu ailede elendi".
5. **Law.** (a) Nested-evidence sufficiency [PROOF]: in an absorbing world failures at `f_1 < … < f_k = f` jointly assert only `τ > f`; multiplying absolute-time survivals at each failure is double counting; the correct product telescopes to `(1−h_i)^f`. (b) Waiting is not observation: updating weights during unobserved time "gözlenmemiş 'hâlâ kapalı' etiketini gizlice kullanmak olur" (`UNKNOWN_CHANGE_AUDIT.md:41`). (c) Non-identifiability: a finite number of failures never proves `h=0` (after a failure at step 240 the weight is only .614883); one success eliminates `h=0` but does not separate two positive rates — one life yields one geometric sample. (d) Cost–discovery impossibility [PROOF by coupling, `UNKNOWN_CHANGE_AUDIT.md:147-164`]: let `W0` never change and `Wτ` open permanently at `τ`, with only costly probes informative, fixed cost `c > 0`, no side channel. With `L` the time of the last probe in `W0`, `P_{Wτ}(eventual detection) = P_{W0}(L ≥ τ)`. If the expected lifetime probing cost in `W0` is finite then the number of probes is almost surely finite, `L < ∞`, and `lim_{τ→∞} P_{Wτ}(detection) = 0`. Converse: a uniform detection floor `δ > 0` for all late `τ` forces `P_{W0}(infinitely many probes) ≥ δ` and infinite expected cost. No internal counter, random deviation or more elaborate computation escapes it under the same observation and cost assumptions.
6. **Limits.** Admitted: the candidate set, the prior, absorption, noiseless probes and rewards are supplied; "Bayes güncelleme kuralını, ödülü, kalıcı açılma varsayımını veya hipotez dilini kendisi keşfetmez"; the growing probe intervals are partly due to the shrinking horizon, not only to learning; after a success followed by a failure the Bayesian normalisation is undefined (a zero-probability event). The audit states that no causal leak and no Bellman index error were found. *Limit I see*: prior-average optimality hides losses in individual worlds — at c=20 the updating policy is 26.3 utility units behind the frozen one inside its own support (`h=.02`) and 32.9 behind outside it (`h=.08`); the model class has no way to grow.
7. **Implication.** *Mechanisms to reuse*: sufficient statistics that compress history without losing what later updates need; two ledgers — prediction that evolves with internal time, and belief weights that move only on real outcomes (this is the exact separation an imagining core needs between simulated and observed); the retest schedule as a consequence of belief rather than a constant. *Requirement*: the goal "never be a prisoner of the past" must be stated with horizon, cost and information channels ("Hangi değişimleri hangi ufukta, hangi bedelle ve hangi bilgi kanallarıyla yeniden sınayacağımız açıkça tanımlanmalıdır"); a zero-probability event must be recorded as insufficient model support, not absorbed silently. *Warning*: updating beliefs can reduce probing and miss fast worlds.

4. **Results.** Analytical points [PROOF or arithmetic]: belief and decision are different quantities — with gain `G` and loss `L` an attempt is preferred iff `p < G/(G+L)`; for `G=1, L=19` the threshold is .05 and a move from .049 to .051 flips the action, so "Büyük davranış farkı büyük bilgi kazanımı veya büyük iç yapı değişimi gerektirmez"; one strongly discriminating event can move a prior of .01 to .5025 (likelihood ratio 100). `P(r given a,o)` is not `P(r given do(a),o)`; own randomised action removes some confounders but "uygulanmış eylemin gerçek sonucu ile yalnız hayal edilmiş karşı-olgusal sonucu aynı bilgi türüne dönüştürmez". Capacity versus difficulty: with `P(Y=1) = σ(c−d)` every pair `(c+k, d+k)` gives the same distribution; more of the same data never resolves it. Safety versus reopening: if the only discriminating action is irreversibly harmful in `W0`, zero-catastrophe and guaranteed discovery cannot both hold. Value of a free observation (EVSI) is non-negative; a costly, world-changing test needs cost, harm, changed state and remaining opportunities; Shannon information cannot stand in for decision value.
   The phenomenon table (§10) gives a status per observation; the recurring verdicts are "yerel destek" inside the small families and "açık" for autonomous discovery. The claims table of `RESEARCH_LOG.md` (25 rows) is reproduced in the Established / Refuted / Open table at the end of this file.
5. **Law.** Importance of an experience is not one scalar: at least three separately measurable changes — belief about the world, the future action distribution, and obtained value/risk. "Sapma ya hatadır ya da temel öğrenme bileşenidir" is rejected as a false dichotomy: the required property is "hedeflenen değişimleri saptayabilecek bilgiye erişimin hangi koşullarda korunabildiği".
6. **Limits.** Admitted: the literature scan "özgünlük ispatı veya 2026 literatürünün eksiksiz değerlendirmesi değildir"; two helper agents were cut off and their work is not counted as independent verification; the log is retrospective, not a preregistration; no biological claim is made anywhere.
7. **Implication.** *Requirement*: the core must keep world belief, action tendency and value as three quantities (a single "confidence" or "surprise" number is refuted as sufficient); it must separate "tried more" from "can now do it" by calibration tasks. *Warning*: nearly every mechanism the programme used has a named precedent (`SOURCES.md` table "Hangi alternatif neyi açıklıyor?") — novelty has to be claimed for a measured contract, not for a component.

## 6. The reassessment: `docs/research/living_learning_reassessment_2026_09_20/` + `research/living_learning_reassessment/` (reprinted as paper 04)

### 6.1 `SCOPE_AND_FOUNDATIONS.md` — what state must be kept

1. **Question.** After the owner's correction that retesting is only a sub-problem, what determines whether a stored state can support not just today's answers but tomorrow's learning, correction and re-representation?
2. **Mechanism / state.** Analytical. `h` = received history, `c(h)` = stored state, `z` = a new experience, `q` = a query, `F(hz,q)` = the target one wants to evaluate with respect to the full history.
3. **Design.** Proofs and minimal counterexamples; a classification table of every earlier result by scientific status.
4. **Results.**
   - Proposition 1, exact online updatability [PROOF, lines 35-43]: a function `u` with `c(hz) = u(c(h), z)` on reachable histories exists if and only if `c(h) = c(h') ⇒ c(hz) = c(h'z)` for every commonly admissible `z`. It is an existence statement: it does not make `u` computable in bounded resources, learnable or efficient.
   - Counterexample for "an answer-sufficient state suffices" [EXACT]: `h = (0,2)` and `h' = (1)` both have mean 1; after a new 4 the correct means are 2 and 2.5. "Mevcut cevabı vermeye yeterli tek sayı, sonraki öğrenmeyi doğru sürdürmeye yeterli değildir." `(sum, count)` repairs addition.
   - History equivalence relative to the future [definition, lines 49-55]: `h ≡_{Z,Q} h'  ⟺  F(hz,q) = F(h'z,q) for all z ∈ Z, q ∈ Q`. With `z = ε` it tests only present behaviour; over all admissible continuations it says which distinctions between pasts must be preserved.
   - Counterexample for "an addition-sufficient state suffices for correction" [EXACT, lines 65-72]: histories `{A=0, B=2}` and `{A=1, B=1}` both store `(2, 2)`; after "remove record A" the correct means are 2 and 1.
   - Proposition 2, exact representation transport [PROOF, line 86]: a map `T` with `φ1(x) = T(φ0(x))` exists if and only if `φ0(x) = φ0(x') ⇒ φ1(x) = φ1(x')`. Three different events follow: the needed information was erased; the information exists but the reader is incompatible (`φ1 = Aφ0`, `w1 = A^{-T} w0` restores the output); adaptation is possible but not found within the budget.
   - Research hypotheses H1–H4 [SUGGESTED, each with a narrow witness]: H1 a state representing future update needs sustains learning over wider continuation families than one preserving only today's output; H2 the information sets sufficient for acquisition, use and correction differ; H3 the benefit of a new representation for a new task does not predict its lifelong benefit; H4 structure acquired in life can lower the learning cost of new tasks, to be shown by better updating under the same new evidence.
   - Requirement inflation corrected: "kontrollü, kalıcı ve genellenebilir" is not zero error in all worlds; the impossibility examples "ana problem için … 'genel ilke bulunamaz' sonucu çıkmaz".
5. **Law.** **The family of future operations determines the state that must be kept.** Precisely: a stored state is adequate for a family `(Z, Q)` of future continuations and queries exactly when it never merges two histories that some `z ∈ Z, q ∈ Q` would tell apart; adequacy for answering (`Z = {ε}`), for continued learning (`Z` = appended experiences), for retraction (`Z` includes deletions) and for a later representation (re-encoding, Proposition 2) can be four different contracts — the documents' wording is "farklı yeterlilik sözleşmeleri olabilir" — and three exact counterexamples show each step of the chain to be strict in at least one family (mean; sum-and-count; parity). Scope: exact (deterministic) case; "Stokastik durumlarda uygun karşılık eşit çıktı dağılımları ve güncelleme çekirdekleriyle kurulmalıdır." Rests on the proofs and three counterexamples above. Acknowledged as not new: causal states (Shalizi and Crutchfield) and predictive state representations (Littman, Sutton, Singh).
6. **Limits.** Admitted: "Bu tanımda gelecek cevaplar zaten biliniyormuş gibi bir oracle kullanılarak algoritma yazılamaz; tanım, önerilen sıkıştırmanın hangi karşı örnekle yanlışlanacağını belirtir"; preserving all continuations equally is not a resource goal; "H1–H4 de dört zorunlu modül veya bulunmuş temel yasa değildir". *Limit I see*: the law says what a state must distinguish once `(Z,Q)` is fixed; choosing `(Z,Q)` under bounded memory — the real design problem — is untouched, and no approximate version (tolerance, weights on continuations) was worked out.
7. **Implication.** *Requirement*: the new core must declare, for each kind of belief it stores, which future operations that belief is meant to survive (answer / continue learning / retract / re-represent) and carry the corresponding state; a core whose weights are graded beliefs must store, next to each weight, whatever its update needs — not just its value. Report on three scales (lines 131-135): immediate capability, continuation capability, change in learning. *Mechanism to reuse*: the equivalence relation as a test generator — to refute a compression, exhibit two histories it merges and one continuation that separates them. *Open*: which distinctions to keep when the future family is unknown.

### 6.2 `REPRESENTATION_GROWTH.md` + `representation_growth.py`

1. **Question.** Can labelled experience create executable feature definitions (not only coefficients) that are then used by later computations and later features, and does growing beat a fixed structure of the same expressive power?
2. **Mechanism / state.** Symbolic feature network over F_101 with inputs `x ∈ F_101^5`. Start `Φ0 = (1, x0..x4)`; per task `j` a linear head `f_j(x) = Σ w_{j,φ} φ(x) mod 101`. A feature is an executable node with two parents, evaluated recursively (`evaluate`, `representation_growth.py:121-149`). Learning loop (`observe`, `:154-188`): predict first; a contradiction with an accepted head deletes that head (`:157-160`); otherwise buffer rows; at 16 rows search — first an exact fit with the active features by Gaussian elimination (`fit`, `:47-77`), failing that, candidates from the generator `G(Φ_t) = {φ·x_i : φ ∈ Φ_t, i ∉ vars(φ), degree(φ) < 3} \ Φ_t` in (degree, coordinates) order (`candidates`, `:91-108`; `discover`, `:110-119`); the first exact fit is validated on the next 4 fresh rows; on success the feature and head are accepted and the raw window is deleted (`:187`). At most 20 raw rows are ever buffered.
3. **Design.** 20 seeds; per life three tasks in order: a pair product, a triple that uses that pair, an independent pair; 20 labelled rows and 100 disjoint held-out inputs per task. Methods: `fixed_linear`; `growth`; `fixed_expanded_sparse` (all 26 features of degree ≤ 3 present, same sparse search); `fixed_expanded_lazy` (26 features present, the growing method's candidate order and activation policy). Interventions (`run_seed`, `:258-297`): block or physically delete a learned node, reset state, one corrupted label, a random-label block, a rule change under the same task id, the triple task without its prerequisite pair.

5. **Law.** (a) Head insufficiency by mixed difference [PROOF, checked in `audit`, `:305-315`]: every `a + b·x0 + c·x1` has zero mixed difference on the square (0,0),(1,0),(0,1),(1,1); `x0·x1` has 1; so the linear head cannot represent it — a statement about the head class, not about information in the input. (b) Lazy-registry equivalence [EXACT, empirical in this language]: growing a feature when evidence demands it is behaviourally and computationally the same as activating it in a pre-enumerated registry under the same policy; only explicit storage differs, and that is "genel bellek alt sınırı" neither. (c) Reachability: a generator that only extends accepted features cannot reach a target whose intermediate does not by itself explain the data.

7. **Implication.** *Mechanism to reuse*: concepts as executable nodes with recorded parents, so that removal of a node is a causal test and a later concept can be built from an earlier one; discover on a window, validate on fresh rows, then drop the window. *Warnings*: "formed when needed" has no advantage over "already latent and activated when needed" unless the latent set cannot be enumerated or stored — the new core must locate its advantage there or in cost; need-driven single-step construction is blind to stepping stones ("Bir özellik bugün işe yaramıyorsa hiçbir gelecek beceri için değer taşımaz" is flagged as a dangerous assumption); a single wrong label still destroys a correct construction. *Open* (line 101): "aynı öğrenme dili, aynı deneyimler ve aynı toplam kaynak altında hangi deneyime bağlı oluşturma/etkinleştirme politikası işe yarar; hangi dağılım veya müfredat değişiminde zarar verir?"

### 6.3 `CREDIT_ASSIGNMENT.md` + `credit_assignment.py`

1. **Question.** If feedback arrives late and all skills share the same parameters, is writing the feedback to the right past experience enough to learn the new and keep the still-valid old, and is replaying raw experience necessary?
2. **Mechanism / state.** Numeric. One shared linear predictor `w·x`, `x = (1, u, v)`, three weights starting at zero. True relation for the whole life: `f(x) = 0.3 + 1.2u − 1.7v` (`credit_assignment.py:42-46`). Phase 1 (600 requests) `v = 0`; phase 2 (600 requests) `v = u`; the boundary is not given to the learners. Labels `y = f(x) + N(0, 0.1²)`, delayed by 1…31 steps, arriving with the correct episode id; pending trace = id → x, capacity 64 (`:152-156`). Updates: normalised gradient step `w ← w − 0.12 (w·x − y) x / ‖x‖²` (`:63-67`); recursive least squares with Sherman–Morrison, state `(w, G^{-1})` where `G = I + Σ x xᵀ` (`:69-80`); reservoir replay buffer of 32 (x, label) records with no task metadata (`:166-175`). Methods (`receive`, `:82-97`): `initial_frozen`, `frozen_after_old` (boundary-informed diagnostic), `current_two` (writes the late label onto the present input), `anchored_one`, `anchored_two`, `anchored_replay` (one anchored step + one replay step), `online_rls`.
3. **Design.** 32 paired seeds, separate random streams for inputs, delays and replay; 1,024 held-out points each for old inputs, new inputs and unseen combinations (`u`, `v` independent); final clean MSE; Student-t 95% intervals with 31 degrees of freedom. Equal gradient budget asserted for `current_two`, `anchored_two`, `anchored_replay` (2,368.3125 evaluations on average, `:196`). Four negative regimes: immediate feedback, insufficient trace (delay up to 127, capacity 4), incompatible drift (slope `+1.2 → −1.2` with no distinguishing feature), misspecified model (`+0.8u²`). One configuration, no sweep.
4. **Results and labels** (`results/credit_assignment.json`, [MC n=32]; an independent rerun reproduced the full JSON, `credit_assignment_verification.json`):

What is missing is the old direction, which phase 2 alone does not determine and which stored statistics or examples would constrain. (c) Conflict floor [PROOF]: two targets differing by `Δ` on the same `x` force a mean of the two squared errors of at least `Δ²/4` (population floor 0.48 in the drift world). (d) Three kinds of state: sufficient to answer (3 weights), sufficient to keep learning (weights + `G^{-1}`), and a validity record for assumptions that may later fail — "Bu deneyde ilk ikisi somut ayrılır; üçüncüsü çözülmez."
6. **Limits.** Admitted: the episode id is delivered from outside ("deney hangi geçmiş eylemin etkili olduğunu … kendisi bulmuyor"); numeric supervised labels, not sparse reward; fixed known representation; RLS is not FLOP-matched; no forgetting factor or change detection was tried; known subject (delayed online learning, CLEAR-style replay, standard RLS). *Limit I see*: trace capacity must cover the delay — the failure regime is an engineering consequence of capacity 4 against delays up to 127, and the observed need in the main regime was a maximum of about 23.6 pending records for delays up to 31.
7. **Implication.** *Mechanism to reuse*: RLS is the smallest working instance of "weights as graded beliefs" — a value plus a per-direction amount of accumulated evidence; it kept the old skill and learned the new one without storing a single raw example. *Requirement*: graded belief needs a validity dimension in addition to precision; a belief that only accumulates becomes the worst performer after a real change. *Warning*: writing an outcome onto whatever is currently active (no trace of the past computation) costs 0.10 MSE here and destroys composition. *Open*: finding the responsible past computation without a supplied id; telling valid old from invalid old.

5. **Law.** (a) Function equivalence is weaker than learning equivalence [PROOF by substitution and induction, lines 13-30]: `vᵀz = wᵀx` for all inputs, and the future trajectories coincide for any shared `(x,y)` stream if and only if the update state is transported as `P_z = A^{-T} P A^{-1}`; with the identity metric in the new coordinates the effective old-coordinate update becomes `w⁺ = w − η AᵀA (wᵀx − y) x`. (b) Two different obstacles: incompatible reading/updating (curable by transport) and information that is really gone (not curable without extra access); worst-world bound for the parity witness: any common prediction `v` has mean squared error `v² + 1 ≥ 1` in at least one world.
6. **Limits.** Admitted: "Deneyde dönüşüm ve doğru matematik araştırmacı tarafından verilmiştir. Sistemin kendisinin yararlı dönüşümü bulduğu … gösterilmedi"; the full transport stores nine more numbers; not an optimiser comparison — the changed dynamics "bazı problemlerde faydalı da olabilir"; related to natural gradient and Net2Net. *Limit I see*: purely linear; the result is the clean statement of a problem every self-reorganising core has, not a method.
7. **Implication.** *Requirement*: whenever the core re-codes itself (forms a concept, merges or splits units), it must transport update state as well as outputs, or knowingly accept a different learner afterwards; it must also decide beforehand what residue of experience to keep for representations that do not yet exist. *Mechanism to reuse*: the three-way diagnosis for any failure after re-representation — erased, mis-read, or not found in budget. *Open*: "gelecekte hangi ayrımların yararlı olacağı bilinmezken neyin tutulacağı".

### 6.5 `REPORT_TR.md` (reassessment synthesis)

1. **Question.** What did moving beyond retesting add, and what is still open in the whole problem?
2. **Mechanism.** A proposed measurement, not a mechanism (lines 56-62): learnability of a state `A_{P,k,B,C}(s) = E_{f,E_k}[ R_{Q_f,B}( U^k_C(s, E_k); f ) ]` — expected risk on a future task family `P` after `k` matched examples and total update budget `C`. ## 8. The pattern of erased advantages

Every apparent advantage in this group vanished against the strongest equal-information baseline. This is the single most important warning for the new initiative.

| First impression | Strong baseline that erased it | What was left |
|---|---|---|
| Witness filtering learns from fewer observations | plain search, same language/order/complete check | a change in work count, sign depends on the world |
| A learned rule is more than stored examples | raw examples + the same induction, done once | persistence without raw records; when the inference is paid |
| Idle "sleep" processing adds knowledge | compile at first request | the same total work; only latency moves |
| Growing a representation beats a fixed one | fixed expanded registry with the same activation policy | identical behaviour and counters; explicit storage differs |
| Replay is how old skills are kept | online sufficient statistics (RLS) | RLS is better and stores no raw example |
| Correct Bayesian updating is always better | frozen hyper-prior in the fast world; out-of-support hazard | better only on the prior average |
| More exploration is better | never probing, in the eight-step world | negative utility for every probing policy |

Consequence: the new core cannot define its merit as "it learns while running" or "it forms concepts" — those were matched. A defensible merit must be stated in a currency the strong baselines cannot match at equal information: bounded memory or compute per step, deadline placement, exact retraction, behaviour after a real change, or the learnability measure `A_{P,k,B,C}`.

## 9. What this group implies for a core in which learning and running are one process

**Requirements**

- R1. One loop: predict, act or answer, receive the real outcome, update — with the update procedure allowed to be part of the state (`s = (θ, η)`, `θ' = U_η(θ, z)`, fixed interpreter). [L3, 5.1]
- R2. Every stored belief declares which future operations it must survive (answer / continue learning / retract / re-represent) and carries the state those need. A weight that is a graded belief is at least (value, accumulated evidence, validity conditions, provenance of the evidence, version of the machinery that produced it). [L12–L16, section 2]
- R3. Two ledgers that never mix: what the system computed or imagined internally (predictions that drift with internal time, compiled structures, hypothetical outcomes) and what the world returned. Only the second moves belief weights. [L4, L11]
- R4. "How real is this construction" is a statement about external discriminating outcomes with a sample bill, or a proof; a finite internal consistency check is not it. Scoring is three-valued: right, wrong, abstained. [L18, L20, section 4]
- R5. The loop must include behaviour → which evidence can arrive, and the core must be able to compute, for a belief, the observation that would refute it and an action that reaches that observation. [L9, 5.4]
- R6. Evaluation on three scales with reset and transplant controls: immediate capability, continuation capability, change in learning; always with the family-shift or changed-world condition and the strongest equal-information baseline. [L2, section 8]
- R7. Re-coding (concept formation, splitting, merging) transports update state together with outputs, or records that the learner has changed. [L15]

**Warnings**

- W1. Binary accept/revoke on a contradiction fails on the first wrong label (affine: correct rule revoked; representation growth: correct head removed in 20/20 lives). No study in this group separates noise from change.
- W2. Belief that only accumulates is the worst performer after a real change (RLS new-input MSE 0.509150 versus 0.001106). Precision without validity is a trap.
- W3. A concept formed later cannot be informed by experience that was summarised before it existed unless the needed distinction was kept (parity witness).
- W4. Need-driven single-step construction cannot reach targets whose stepping stones do not pay by themselves (0/2,000).
- W5. A better constructor transfers inside the family it was formed in and costs a computable amount outside (+0.4188 mistakes, +4.643856 bits).
- W6. Time-to-first-success is a misleading learning metric (the scrambled control "wins" it while being worse).
- W7. Zero forgetting, zero wrong learning, zero risk and unbounded capacity in bounded state are excluded by proof; "never a prisoner of the past" needs a horizon, a cost and an information channel.
- W8. Nothing in this group shows that leaving the Transformer, the embedding table or softmax is necessary; the reports say so explicitly. The case for the new core has to be made by measurement, not inherited from these studies.

**Mechanisms to reuse** (file references in the sections above)

- M1. Provenance ledger with beliefs recomputed from retained evidence; one count per independent sample; per-source supersession; logged propensities.
- M2. Version-stamped dependencies with invalidation of derivatives and abstain-until-revalidated.
- M3. Witness (two histories merged by the current key with different outcomes) as the trigger that a distinction is missing.
- M4. Executable concept nodes with recorded parents; discover on a small window, validate on fresh rows, drop the window.
- M5. Value-plus-precision beliefs updated recursively (the RLS pattern) as the minimal graded-belief unit.
- M6. Never-zero hypothesis mass, which keeps identification intact and bounds the cost of a wrong habit.
- M7. Sufficient statistics that collapse nested evidence; belief-state value computation from which information-seeking follows without a curiosity term; deterministic internal state as a source of re-testing.
- M8. Experimental hygiene: frozen predictions before labels, explicit work meters that charge a method for its own setup, `inconclusive` under resource cuts, persistent-state transplant and fresh-process restart, negative controls kept in the record.

**Open questions inherited**

- O1. Where candidate distinctions and operation languages come from (every language in this group was supplied).
- O2. Attributing a late outcome to the responsible past computation without a supplied id.
- O3. What residue of experience to keep when the future family of operations is unknown.
- O4. Telling a wrong label from a changed world from a wrong representation.
- O5. Whether the construction procedure itself can improve in a way not explained by carried answers or an easy family.
- O6. All of the above in one life, on one state, with bounded memory and compute.
- O7. Separating "the world does not allow it" from "I could not do it then".
